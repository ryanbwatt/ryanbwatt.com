This site is a set of pages rather than a blog. No dates, no feed, nothing
that implies a schedule. A page here is something I expect to revise for
years, not an entry filed under a month. The structure is borrowed from
[patrickcollison.com](https://patrickcollison.com), which treats a personal
site as a commonplace book.

The look is borrowed from the same place. Text is 13px Helvetica on white,
the links are blue and underlined, the nav sits in a narrow column at the top
right, and most of the page is empty. Nothing is centred and nothing scales
to fill the window.

There is no webfont. The page renders in whatever sans-serif your computer
already has. There are no CSS variables, no framework, no design system, and
no dark mode. The stylesheet is about a hundred lines, written by hand, served
at [/style.css](/style.css) exactly as it was typed — no bundler touches it.

Built with [Astro](https://astro.build), which turns Markdown files into
static HTML and does nothing else here. Hosted on Cloudflare Pages. No
JavaScript, no analytics, no cookies, no external requests of any kind.
