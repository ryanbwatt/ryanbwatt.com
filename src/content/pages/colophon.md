This site is a set of pages rather than a blog. No dates, no feed, nothing
that implies a schedule. A page here is something I expect to revise for
years, not an entry filed under a month.

Text is 13px Helvetica on white. Links are blue and underlined, and turn black
on the page you're reading. The nav sits in a narrow column at the top right
and the text sits in a fixed column set in from the left. Nothing is centred,
nothing stretches to fill the window, and most of the page is empty.

There is no webfont — the page renders in whatever sans-serif your computer
already has. No CSS variables, no framework, no design system, no dark mode.
The stylesheet is about a hundred lines, written by hand, and served at
[/style.css](/style.css) exactly as it was typed. No bundler touches it.

Built with [Astro](https://astro.build), which turns Markdown files into
static HTML and does nothing else here. Hosted on Cloudflare Pages. No
JavaScript, no analytics, no cookies, no external requests of any kind.
